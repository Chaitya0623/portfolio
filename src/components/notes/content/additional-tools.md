## Building Blocks

- **Jina AI:** developers can build cross-modal and multi-modal systems on the cloud (accepts multiple forms of input -> text, images, can produce various forms of output)
- **Mini-LLM:** minimal system for running modern LLM on consumer grade GPU's
- **Streamlit:** open source python framework, can create direct visualization, interface eliminating the need for frontend (can integrate with API's too). Create charts, components, maps, images, all types of input, chatbot, audio, video, forms, SQL connection. https://docs.streamlit.io/develop/api-reference
- **Supabase:** open source firebase alternative. Create PostgreSQL database, authentication, instant api's, real time subscriptions, storage and vector embeddings
- **Flask/FastAPI:** create backend endpoints using just one python file. Can integrate ML models https://github.com/Chaitya0623/Infiheal_Codes/blob/main/fastapi.py
- **PythonAnywhere:** host django backend
- **Render:** host python backend endpoints for free (will have cold start issues as the server is not always on)
- **Vercel/Netlify:** host frontend for free, Vercel can also run backend code as serverless functions (configure with vercel.json)
- **Lotus:** semantic search over data https://github.com/guestrin-lab/lotus
- Prompt generation for ChatGPT https://github.com/ncwilson78/System-Prompt-Library https://docs.easyprompt.xyz/easyprompt/product/easyprompt-library
- **Gitbook:** Github for documentation https://www.gitbook.com/

## Agents and Simulation

- **Swarm:** multi agent systems https://github.com/openai/swarm allows you to redirect from one agent to another, thereby using multiple at the same time giving the flexibility to choose an agent as per use case
- **AgentTorch:** https://github.com/AgentTorch/AgentTorch get graphs, stats, insights as chatbot responses to your custom data (tuned for population data), also gives geopolitical graphs and stats
- **Oasis:** https://github.com/camel-ai/oasis mimic social media environment, it creates agents that mimic the behaviour of users. Thus, helping us make better predictions (agents can perform actions like follow, like, comment, etc). Can also evaluate different recommendation algorithms. There is a gpt prompt for each and every action, better if we need scalable solutions, not economical for general dashboards.
- **OpenAI Gym:** testing different reinforcement learning algorithms, on various simulated environments, with the goal of maximising the reward with interacting with the environment (now maintained as Gymnasium). https://openai.com/index/openai-gym-beta/ https://www.youtube.com/watch?v=8MC3y7ASoPs
- **FailureSensorIQ:** AI Agent for multiple choice questions https://github.com/IBM/FailureSensorIQ
- **AwesomeMCP:** for deploying MCP servers
